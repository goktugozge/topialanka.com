# Topialanka website

This website requires no extra software. You can open `index.html` in a browser to preview it or upload this folder's contents to a web-hosting account.

## Publishing

Cloudflare Pages and Netlify are the easiest options:

1. Create an empty repository on GitHub and upload the files from this folder.
2. In Cloudflare Pages or Netlify, select that GitHub repository. No build command is needed; the publish directory is the repository root.
3. Add `topialanka.com` in the provider's **Custom domain** section.
4. In the DNS panel at the company where you bought the domain, add the records supplied by the hosting provider.

The contact email address and Instagram link are in `index.html`; update them before publishing.
